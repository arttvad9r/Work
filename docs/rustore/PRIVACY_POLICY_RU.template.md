## 2. Данные, которые пользователь хранит в WorkTime

Пользователь самостоятельно вводит и хранит на своём устройстве:

- даты рабочих записей;
- отработанное время;
- почасовую ставку и сохранённые значения ставки для отдельных записей;
- премии и штрафы;
- ставку по умолчанию;
- выбранную тему приложения.

Эти данные используются локально на устройстве для отображения календаря и расчёта дневных, месячных и годовых итогов.

Текущая версия WorkTime автоматически не передаёт содержимое этих записей разработчику и не создаёт у разработчика их серверную копию.

## 3. Автоматическая передача и сторонние SDK

В текущей версии WorkTime:

- нет рекламных SDK;
- нет аналитических SDK;
- нет SDK автоматического crash-reporting;
- приложение не запрашивает разрешение Android `INTERNET`;
- рабочие записи, сведения о доходе и настройки автоматически не отправляются разработчику или третьим лицам.

Если в будущей версии появится функциональность, которая изменит этот порядок, Политика и сведения в магазинах приложений должны быть обновлены до публикации такой версии.

## 4. Локальное хранение и резервное копирование

Рабочие записи и настройки хранятся в приватном локальном хранилище приложения на устройстве пользователя с использованием Android Room и DataStore.

Облачное резервное копирование Android и автоматический перенос данных приложения между устройствами отключены конфигурацией WorkTime. Фактическое поведение системных механизмов также зависит от версии Android и производителя устройства.

## 5. Экспорт, импорт и внешние сервисы

Экспорт и импорт выполняются только по явному действию пользователя:

- JSON используется для резервной копии и восстановления данных;
- CSV предназначен для просмотра данных в табличных программах;
- место сохранения или файл для чтения пользователь выбирает через системный интерфейс Android.

Если пользователь самостоятельно выбирает облачное хранилище, мессенджер или другое внешнее приложение как место назначения экспортированного файла, дальнейшая обработка этого файла осуществляется выбранным сервисом на его условиях и в соответствии с его политикой конфиденциальности. WorkTime не загружает файл туда автоматически.

## 6. Обращения в поддержку

Если пользователь самостоятельно обращается по адресу `<EMAIL ПОДДЕРЖКИ>`, разработчик может получить данные, которые пользователь укажет в обращении, например адрес электронной почты, имя, текст сообщения и приложенные файлы.

Такие сведения используются для рассмотрения обращения, ответа пользователю, диагностики заявленной проблемы и защиты законных интересов при необходимости. Пользователю не следует направлять сведения, которые не нужны для решения вопроса поддержки.

Данные обращения хранятся не дольше, чем это необходимо для указанных целей, если более длительное хранение не требуется применимым законодательством или для защиты прав и законных интересов разработчика.

## 7. Разрешения устройства

В текущей версии WorkTime не запрашивает доступ к интернету, геопозиции, контактам, камере или микрофону.

Перечень разрешений и зависимостей проверяется по точной release-сборке перед каждой публикацией.

## 8. Удаление данных

Пользователь может удалять отдельные рабочие записи внутри WorkTime.

При удалении приложения локальные данные WorkTime удаляются в соответствии с поведением Android. Экспортированные пользователем файлы находятся вне песочницы приложения и удаляются пользователем отдельно из выбранного места хранения.

WorkTime не создаёт пользовательские аккаунты и не хранит серверную копию рабочих записей или сведений о доходе.

По вопросам удаления данных, содержащихся в обращениях в поддержку, пользователь может написать на `<EMAIL ПОДДЕРЖКИ>`. Запрос исполняется в пределах, допускаемых применимым законодательством.

## 9. RuStore и другие площадки распространения

Установка, обновление и иные действия пользователя в RuStore или другой площадке распространения могут сопровождаться обработкой данных самой площадкой. Такая обработка регулируется документами соответствующей площадки и не является автоматической передачей локальных записей WorkTime разработчику.

## 10. Дети

WorkTime не содержит контента, требующего возрастного ограничения выше 0+, и не предназначен для целенаправленного сбора данных детей. Приложение не создаёт аккаунты и автоматически не отправляет пользовательские рабочие записи на сервер разработчика.

## 11. Изменения Политики

Политика может обновляться при изменении функциональности приложения, состава зависимостей, порядка работы с данными или требований законодательства.

Актуальная редакция публикуется по постоянной публичной ссылке, указанной в карточке приложения RuStore. Для версии приложения применяется редакция Политики, действующая на момент её публикации, если новая редакция прямо не устанавливает иное в пределах, допускаемых законодательством.
