## 2. Какие данные обрабатывает WorkTime

WorkTime предназначен для локального учёта рабочего времени и ожидаемого дохода. Пользователь самостоятельно вводит и хранит на своём устройстве:

- даты рабочих записей;
- отработанное время;
- почасовую ставку;
- премии и штрафы;
- настройки приложения, включая ставку по умолчанию и выбранную тему.

Эти данные используются для отображения календаря и расчёта дневных, месячных и годовых итогов.

## 3. Передача данных

Текущая версия WorkTime не требует учётной записи и не содержит рекламных, аналитических или crash-reporting SDK. Приложение не запрашивает разрешение Android `INTERNET` и автоматически не отправляет рабочие записи, сведения о доходе или настройки разработчику либо третьим лицам.

## 4. Локальное хранение

Рабочие записи и настройки хранятся в локальном хранилище приложения на устройстве пользователя с использованием Android Room и DataStore.

Облачное резервное копирование Android и автоматический перенос данных приложения между устройствами отключены конфигурацией приложения.

## 5. Экспорт и импорт

Экспорт и импорт выполняются только по явному действию пользователя:

- JSON используется для резервной копии и восстановления данных;
- CSV предназначен для просмотра данных в табличных программах;
- место сохранения или файл для чтения пользователь выбирает через системный интерфейс Android.

Если пользователь самостоятельно выбирает облачное хранилище, мессенджер или другое внешнее приложение как место назначения экспортированного файла, дальнейшая обработка такого файла регулируется правилами выбранного сервиса. WorkTime не загружает файл туда автоматически.

## 6. Разрешения устройства

В текущей версии WorkTime не запрашивает доступ к интернету, геопозиции, контактам, камере или микрофону.

Перед каждой новой публикацией перечень разрешений и зависимостей должен проверяться повторно. Если функциональность приложения изменится, эта Политика будет обновлена до выпуска соответствующей версии.

## 7. Удаление данных

Пользователь может удалять отдельные рабочие записи внутри приложения. При удалении WorkTime локальные данные приложения удаляются в соответствии с поведением Android.

Файлы, которые пользователь ранее экспортировал за пределы хранилища приложения, находятся вне песочницы WorkTime и удаляются пользователем самостоятельно в выбранном месте хранения.

WorkTime не создаёт пользовательские аккаунты и не хранит серверную копию рабочих записей или сведений о доходе.

## 8. Дети

WorkTime не содержит контента, требующего возрастных ограничений выше 0+, и не предназначен для целенаправленного сбора данных детей. Приложение не создаёт аккаунты и не отправляет пользовательские записи на сервер разработчика.

## 9. Изменения Политики

Политика может обновляться при изменении функциональности приложения, состава зависимостей или требований законодательства. Актуальная редакция публикуется по постоянной публичной ссылке, указанной в карточке приложения RuStore.
